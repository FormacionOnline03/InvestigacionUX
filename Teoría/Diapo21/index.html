Las fases del producto

01 / Fase de discovery

¿Qué se hace en esta fase?

En esta fase se explora el problema.

¿Qué está pasando?

El problema aún no está claro. Es importante que entendamos necesidades, comportamientos y contexto.

Técnicas adecuadas

En esta fase, las técnicas adecuadas son las entrevistas en profundidad, la observación contextual, el shadowing y los estudios etnográficos.

Error típico

Usar A/B testing o encuestas en esta fase sin entender aún el problema.

02 / Percepción de utilidad

¿Qué se hace en esta fase?

En esta fase se evalúa cómo solucionar el problema.

¿Qué está pasando?

Ya hay una propuesta o un diseño y queremos comprobar si funciona.

Técnicas adecuadas

Para esta fase se eligen técnicas como tests de usabilidad moderados, tests de usabilidad no moderados, evaluación heurística o recorrido cognitivo.

Error típico

Seguir haciendo entrevistas cuando ya necesitas evaluar interacción real.

03 / Fase de producto en uso

¿Qué se hace en esta fase?

En esta fase se mide y optimiza.

¿Qué está pasando?

La propuesta ya está en producción. Queremos medir rendimiento y escalar decisiones.

Técnicas adecuadas

Se trabaja con técnicas como analítica digital, encuestas y A/B testing.

Error típico

Intentar medir con entrevistas lo que requiere datos a escala.
